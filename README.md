# RSD Style Salon | Promotional Website

A fully responsive, multi-page static website designed for **RSD Style Salon** (Robinson Homes East). This project was built as the final requirement for **ICOM111 - Introduction to Computing**.

## 🚀 Live Website
You can view the live, deployed website here: 
**[https://rhiannerhiaaa.github.io/RSD-Style-Salon/](https://rhiannerhiaaa.github.io/RSD-Style-Salon/)**

## ✨ Features
*   **Multi-Page Layout:** Home, Hair, Makeup, Waxing, and Contact pages.
*   **Custom Aesthetic:** Elegant, feminine design inspired by the salon's physical flyers (Cream, Blush, and Dusty Rose color palette).
*   **Interactive Elements:** 
    *   Hover effects with a gold glow on the hair portfolio gallery.
    *   "Before & After" transformation section.
    *   "Why Choose Us" and Client Testimonials sections.
*   **Responsive Design:** Fully optimized for mobile phones, tablets, and desktops.
*   **Custom Typography:** Utilizes Georgia and Arial (Web Safe Fonts) with specific letter-spacing to mimic high-end editorial design.
*   **Dynamic UI:** Sticky navigation bar that shrinks on scroll, a smooth "Back to Top" button, and elegant CSS fade-in animations.
*   **Functional Contact:** Clickable phone numbers, email links, and direct Messenger integration.

## 🛠️ Technologies Used
*   **HTML5:** Semantic structure and content.
*   **CSS3:** Custom variables (colors), Flexbox, CSS Grid, media queries, and keyframe animations.
*   **JavaScript (Vanilla):** Simple scroll event listeners for the shrinking navigation bar and the "Back to Top" button.
*   **GitHub Pages:** For free static site hosting.
